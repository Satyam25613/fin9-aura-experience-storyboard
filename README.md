# Fin9 Aura experience storyboard

A responsive stakeholder concept for Aura’s meeting preparation experience. The infographic report combines the 0–8 journey, a parallel-work diagram, interactive example charts, and the advisor’s review boundary.

## Preview

For local development, run `cd app && npm install && npm run dev`. The repository root also contains the latest static build in `index.html` and `assets/` for a static host.

## Rebuild

From `app/`, run `npm install` and then `npm run build:site`. The app source uses React, Tailwind CSS v4, and shadcn/ui components. The diagram and metric visuals use the C3aLabs monochrome tokens.

## Review context

This is a concept artifact based on the supplied experience brief. Scenario values, client details, and generated grayscale scenes are illustrative; no live market, portfolio, risk, or goal records are included. Product behavior described in the brief should be validated before it is presented as implemented behavior. The attached storyboard image informed the 0–8 stage sequence; its sample metrics and role labels are not reproduced.
